# MyClarks Kenya - E-commerce Website

A responsive e-commerce website for MyClarks Kenya, selling leather, casual, and formal shoes online.

## Features

- Responsive design that works on all devices
- Product catalog with filtering options
- Shopping cart functionality
- Kenyan Shilling (KES) currency
- Modern UI/UX design inspired by Clarks official website
